HOW TO PUT IT ONLINE (make it a real website)
---------------------------------------------
1. Buy a domain name (example: gracedistribution.com)
   - Try: Hostinger.com, Namecheap.com, or any local provider in Pakistan.
   - Cost: about Rs 2,000–4,000 per year.

2. Buy hosting (a place to store the website).
   - Hostinger / Namecheap shared hosting is enough (~$30–50 / year).
   - OR use a FREE option: Netlify.com — drag this whole folder onto their
     website and it goes live in minutes (free).

3. Upload ALL the files in this folder (keep the folders css, js, images).
   The "index.html" must stay in the main folder.

EASIEST FREE WAY:
   - Go to  https://app.netlify.com/drop
   - Drag this entire "grace-distribution-website" folder into the page.
   - Your website is live instantly with a free link.
